三人行，必有我师。  

身边的人，谁都可能是你的”师傅“。  

下面盘点那些我不经意间学会的计算机相关小技巧：  

* Windows 中 Shift + Delete 键永久删除文件，不放回收站   
这还是我大学期间从一个室友那里学会的，之前只会选中文件，右键选择删除。  
原来选中文件后，键盘上的 Delete 键也可以删除，更重要的是，对已经确定不再需要的文件，Shift + Delete 键，可以永久删除文件，不放回收站。   

* Windows 系统屏幕截屏，可以使用 Windows 自带的截图工具  
以前只会使用  QQ 的截图功能，每次截图还要把 QQ 打开，太 low 了吧。  
Windows 系统自带截图工具：  
搜索框输入截图，截图工具就出来了。截图时，点击新建即可。  
快捷键 Win+Shift+S。支持矩形、自由形、窗口、全屏截取；可直接复制到剪贴板或保存。  

* Windows 系统快速锁屏：Win + L  
这还晚上我开着电脑，屏幕太亮，影响孩子睡觉，我老婆告诉我的。她还说，你一个程序员，连这都不知道，哈哈。  
因为我平时基本不怎么用 Windows 快捷键，用的最多的一个快捷键是：Ctrl + Alt + Delete，选择"任务管理器”打开。  

* Notepad++ 中的列编辑功能    
这是我工作中最早学会的一个小技巧，毕业刚进公司，从我的师傅那里知道的。文本竟然可以按列编辑！当时确实给我一个小小的震撼。    

* Vim 编辑器中使用 ？进行反向查找    
以前一直只知道正向查找，使用 / ，要反向查找时，只会从头再开始（现在想起来好傻），后来还是从老板那里知道使用 ？就可以反向查找了。  
你会问，老板教你的？确实，我们老板，遇到他关心的事情时，经常会在你旁边看你解决问题！  

* Linux 系统中，查看目录下的文件列表，可以按时间排序查看  
以前查看目录下的文件列表，需要找最新修改的文件时，经常是去看文件的日期，这效率也太低了吧，而且还容易出错。  
最新在前（降序）：使用 ls -lt 命令；  
最旧在前（升序）：使用 ls -ltr 命令；  

* Linux 系统中，把文件大小显示成易读单位的命令：ls -lh  
曾经，Linux 下我想知道文件的大小，是靠看 ls -l 默认输出的字节数的，直到有一天，我发现从字节数估算多少K，多少M的方式，实在是太笨了！  
简单查一下，把文件大小显示成易读单位，so easy!
