# /Library-lint — Library 体检

## 触发条件

- 用户输入 `/Library-lint`
- 用户说"检查 Library"、"Library 体检"、"有没有死链"

## 执行流程

### 1. 索引一致性检查

- 读取 `Library/index.md` 中注册的所有 `[[wikilink]]`
- 扫描 `Library/` 下实际存在的 `.md` 文件
- 对比差异：注册但不存在（死链） vs 存在但未注册（遗漏）

### 2. 双链健康检查

- 扫描所有 wiki 页面中的 `[[wikilink]]`
- 检查链接目标是否存在
- 检查是否存在孤岛页面（没有任何页面链接到它，它也不链接任何页面）

### 3. 知识冲突审计

- 搜索所有 `## 知识冲突` 区块
- 列出未解决的冲突

### 4. 输出健康报告

```
## Library健康报告 [YYYY-MM-DD]

### 索引
- 注册页面数：X
- 实际页面数：Y
- 遗漏注册：[列表]
- 死链：[列表]

### 双链
- 孤岛页面：[列表]
- 断链：[列表]

### 知识冲突
- 未解决冲突：X 处 [列表]

### 建议
- 优先修复项
```

## 约束

- **只读扫描**，不自动修复
- 修复操作需等用户确认后再执行
- 使用简体中文输出报告
